# Calvin Rutherford

I build personal projects around backend services, data pipelines and explicit
application state. I’m interested in how systems handle authorization, failure,
recovery and the gap between a passing test and a working release.

## Selected work

- **[Magistrate](https://github.com/calvin-rutherford/Magistrate)** — an
  engineering-assistant prototype with a FastAPI gateway and Expo Chat/Voice.
  Its [case study](https://github.com/calvin-rutherford/Magistrate/blob/main/docs/portfolio-case-study.md)
  explains architecture, tradeoffs and evidence. Personal execution and
  live/device acceptance remain blocked.
- **[GiniCast](https://github.com/calvin-rutherford/ginicast)** — phase-one
  economic-data acquisition, standardization and metadata auditing in Python.
  Forecasting and interactive dashboards are future work.
- **[Sunset Sheriff](https://github.com/calvin-rutherford/police-simulator)** — a
  Godot 4.5 town-defense game with procedural assets, an economy and checkpoint
  persistence. The repository contains local build and validation instructions.

## Smaller experiments

[Vitatrix](https://github.com/calvin-rutherford/Vitatrix) explores a Spring Boot
notes/handoff API with synthetic demo data.
[Neural IO](https://github.com/calvin-rutherford/neural-io) is a synthetic LSTM
sequence-classification baseline.
[Mood Detector](https://github.com/calvin-rutherford/mood-detector) combines a
text-classification baseline with Streamlit. Their READMEs describe their scope
and limitations.

Tools in these projects include Python, Java, TypeScript, SQL, Bash and GDScript.
See [my portfolio source](https://github.com/calvin-rutherford/My_Site) for the
website and project links.
